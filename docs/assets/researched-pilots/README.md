# Researched character pilots

Open [the comparison page](review.html) to compare native PNG and encoded
AVIF/WebP on light and dark backgrounds at 128 through 1254 displayed pixels.

The three candidates use the approved flat editorial-cartoon direction:

- [Football Tycoon](football-tycoon.png).
- [EU-Funds Alchemist](eu-funds-alchemist.png).
- [Luxury Minister](luxury-minister.png).

Each identity was researched from five distinct, visually inspected web
photographs. The private studies contain source URLs, dates, observed traits,
and the selected appearance. Verified web evidence replaced conflicting
private descriptions. Each initial request attached four identity photos and
one style example, because this chat tool accepts five reference attachments.
The written brief retained observations from all five researched photographs.

The sources are native 1254-square transparent PNGs. The built-in tool did not
expose a backend model. No paid Flare request was made. The source preparation
only cleared detached alpha-1 pixels when native transparency validation
failed. It did not reconstruct a background or change the subject colors.

Each candidate has ten locally encoded variants: AVIF and WebP at 128, 256,
320, 640, and 960 pixels. Native-alpha, silhouette, and byte-budget checks
passed. The review page passed 45 image decode and display-size checks across
three formats and five display sizes. The 1254-pixel encoded view deliberately
enlarges the 960-pixel variant in the browser for comparison.

The production-browser preview substitutes candidate variants in an isolated
browser context. It does not replace shipping files. Evidence includes roster
and setup views, and match views at 640 by 320, 1024 by 768, and 1920 by 1080
with device pixel ratio 1. This does not prove physical-screen appearance at
every device pixel ratio, or any ungenerated pose.

The dossier received one focused correction after the browser preview showed
its lower edge behind the desk. The final compact dossier, stamp, beads, and
phone stay visible above the standing desks. The corrected candidate passed
the same encoding and browser checks. Color validation passed for all three
masters and their 30 variants.

The refactor passed `npm run quality:quick`: 1,314 unit tests, 926 browser
component tests, and 242 end-to-end tests. One unit test, one component test,
and three end-to-end tests were skipped by the suite. Skill validation,
Markdown lint, formatting, and whitespace checks also passed. The full gate
was not requested or run.

These are review candidates. The complete pose packages, human-roster rollout,
and seven scene-background replacements remain pending. Robot art is unchanged.
Temporary prompts, raw outputs, and detailed evidence remain in
`tmp/art-style-trial/researched/`.
