# Character reference library

All 18 reviewed reference masters are separate native 1254-square transparent PNG files.
The [style contract](flat-editorial-style.md) records the rules. The [manifest](character-style-master-manifest.json) records hashes, provenance and all 220 calibrated contour samples.

Each figure and all six body-part medians pass 3.90–4.20 normalized contour units. All heads pass the usual 19–22 percent class.
Generation used the built-in chat tool and owner-authorized local asset preparation.
The short-fat-female and medium-fat-female figures were regenerated from scratch on 2026-10-06
after the owner rejected their chin artifacts and heavy shoe borders.
Both new figures have additional shoe-edge measurements and native jaw and footwear review.
Their preparation uses only their new generated pixels.
The other 16 files remain unchanged; their earlier shoe-only integration preserved source alpha and pixels outside the shoe masks.
